📁 Local vault folder

Each note is saved as a Markdown file with YAML frontmatter in a folder you choose, such as an Obsidian vault. The file name is Title_noteId.md, using the first 6 characters of the note id. These characters in the title become hyphens: < > : " / \ | ? *. Edits made in Obsidian (or any editor) are picked up live.

☁ Google Drive sync

Each note is uploaded as a Markdown file into the folder you choose. Autosave updates that same file (PATCH) instead of creating another copy. Deleting a note moves its Drive file to the trash.

How to get an OAuth client ID and secret
  1. Open Google Cloud Console → Credentials and create (or pick) a project.
  2. Enable the Google Drive API.
  3. Configure the OAuth consent screen (External, add yourself as a test user).
  4. Create credentials → OAuth client ID → application type Desktop app.
  5. Paste the client ID and client secret below, then click Sign in with Google. The browser opens; after you approve, it redirects back to this app on 127.0.0.1.

With drive.file, only folders created by this app are reachable, so use Create a Quick Notes folder instead of pasting an arbitrary folder ID. Sign in again after changing the access level.
